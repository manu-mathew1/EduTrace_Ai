## 🛠️ Recording Production Checklist

1. **Environment Setup:**
   - Run `./run_demo.sh` to pre-seed SQLite database and launch FastAPI (port 8000) and Vite (port 5173).
   - Open Chrome at `http://localhost:5173/` in an incognito window with bookmarks bar hidden.
2. **Audio Setup:**
   - Microphone gain set to prevent clipping; noise suppression enabled.
   - Speak with energetic, confident, authoritative pacing matching the second-by-second table.
3. **Screen Capture:**
   - OBS Studio or QuickTime Player configured for 1920x1080 capture.
   - Smooth mouse movements; no erratic cursor circling.
4. **Backup Video File:**
   - Save rendered MP4 to `docs/pitch/edutrace_demo_backup_1080p.mp4`.
